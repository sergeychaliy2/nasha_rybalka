# Заветная Рыбалка 🎣

Локальный (офлайн) рыболовный симулятор от первого лица с берега, на **Flutter**.
Самостоятельный проект, вдохновлённый жанром; весь контент **оригинальный
(NDA‑safe)** — без реальных брендов, торговых марок, ссылок на магазины и
настоящих призов. Без сетевых запросов и реальных платежей: «премиум» покупается
за внутриигровое золото. Ловля по всему миру: **Континенты → Регионы → Водоёмы**.

> Статус: **играбельная сборка «под ключ»**. Архитектура, доменная логика и
> контент на месте; пройдена полировка интерфейса (анимации, переходы,
> процедурные фоны). Основная цель — Windows (desktop); Android/iOS/Web позже.

## Документация

- `docs/GAME_DESIGN.md` — документ дизайна (мир, экономика, валюты, рыбы, снасти,
  эхолоты, цикл рыбалки, награды, турниры, погода/время).
- `docs/ARCHITECTURE.md` — слои, зависимости, структура, ключевые решения.

## Что уже сделано

- **Доменный слой** (чистый Dart, тестируемый): сущности (мир, локации, рыбы,
  снасти/эхолоты, игрок), value objects (`Money`/`CurrencyType`, `Weight`),
  сервисы — `BiteCalculator` (поклёвка с учётом приманки/времени/погоды/глубины/
  прикормки/проводки), `EconomyService`, `LevelingService`. **Редкость улова
  считается эффективно** (`catchRarity`): база вида + весовой тир → вплоть до
  эпика/легенды; чем легендарнее — тем ниже шанс поклёвки и выше награда.
- **Контент** (`SeedContentRepository`, встроен в код): **6 континентов**, ~10
  регионов, **22 локации** (из них **9 водоёмов РФ по реальной географии** со
  своими процедурными фонами), **~56 видов рыб** (ультра-расширенный бестиарий
  РФ — от уклейки и ерша до калуги, тайменя и тихоокеанских лососей), **100+
  предметов снаряжения** линейками тиров (удочки, спиннинги, катушки, лески,
  крючки, наживки/приманки, эхолоты, перекусы) — без реальных брендов.
- **Состояние**: Riverpod 3, провайдеры в `lib/app/providers.dart`,
  `PlayerController` — сейв (`shared_preferences`), запись улова (трофеи,
  счётчики видов, эффективная редкость, опыт мастерства), покупка/утилизация/
  экипировка, разблокировка регионов и водоёмов, турниры, ежедневная награда,
  ежедневные поручения, энергия, платные советы.
- **Игровая оболочка** (`lib/features/shell/`): постоянный стат-бар (уровень/
  опыт/**энергия**/серебро/золото) и нижняя навигация — Карта · Снаряжение ·
  Магазин · Задания · Бестиарий · Турниры. Окна разделов открываются с анимацией
  (подъём + масштаб + растворение), у кнопок тактильный отклик.
- **Карта** (`lib/features/map/`): реальная **карта России по регионам**
  (проекция Альберса), пины водоёмов, выход на воду. Закрытые регионы/водоёмы
  открываются по уровню и за серебро. Карточка водоёма с вкладками **ИНФО** и
  **СОВЕТЫ** (платные подсказки-намёки по конкретному водоёму). Всплывающая
  ежедневная награда (лесенка 7 дней).
- **Сцена ловли** (`lib/features/fishing/`, рендер **Canvas**):
  - Заброс — тап по воде (без перезаброса, пока снасть в воде); подтверждение
    при выходе к карте.
  - **Поплавок** на поклёвке играет по-разному (окунается / подёргивает /
    ведёт в сторону); подсечка по тапу.
  - **Спиннинг** требует **проводки** (катушкой), чтобы спровоцировать удар;
    под водой видна еле заметная блесна, ярче — у берега.
  - **Глубина** — интерактивный разрез воды: тянешь грузило, видишь профиль дна
    и зону; у каждого вида своя глубина (ловится и вне её, но с меньшим шансом).
  - **Вываживание** тянет рыбу **вниз к берегу**; катушка крутится, удилище
    гнётся. **Прикормка** поднимает активность; **расход наживки** на промахе.
  - Цикл день↔ночь и погода (тинт сцены, дождь). Карточка улова с пружинным
    появлением. Турнирный HUD при активном турнире.
  - Вход на воду — тематический **«занавес-заброс»**: крючок на леске уходит под
    воду, рыба клюёт и идёт наверх, затем открывается сцена.
- **Мета-разделы**: Магазин (карточки со шкалами и сравнением), Снаряжение
  (слот-пикер «экипировать/купить»), Бестиарий (детали видов + трофеи по весу),
  Турниры (вход за плату, боты, призы по местам), **Древо навыков** (в стиле
  ARC Raiders, узлы за «опыт мастерства»), Задания (**Поручения** — ежедневные
  цели с прогрессом + **Цели** — достижения).
- **Энергия**: заброс тратит силы, энергия **копится в реальном времени**
  (см. `Player.currentEnergy`) и **полностью восстанавливается при запуске игры**
  («отдых между сессиями»); перекусы из рюкзака пополняют её сразу.
- **Погода**: процедурный детерминированный прогноз по водоёмам + **карта
  осадков по субъектам РФ** (тучи-радар, таймлайн-ползунок как в Яндексе, зум).
  Прогноз связан со сценой: дождь из прогноза **реально начинается в сессии**
  (1 «час» = 90 с), до его начала действует бонус клёва «перед дождём».
- **Звук** (`SoundService`, audioplayers): 6 **синтезированных** WAV-эффектов
  (всплеск, поклёвка, улов, катушка, писк эхолота, дождь) — сгенерированы кодом,
  оригинальные; тумблер «Звук» применяется сразу.
- **Эхолоты**: 8 моделей с разными наборами возможностей (дуги рыбы, вес,
  термоклин, зум дна, **сигнализатор по диапазону веса** с мигающим маячком…);
  устройство с анимацией включения/выключения; что видно на сонаре — то и клюёт.
- **Арт-пайплайн**: фоны локаций/меню/загрузки, рыбак в инвентаре, баннеры
  категорий магазина и 10 фото рыб сгенерированы ИИ (оригинальные, NDA-safe);
  остальное — процедурный `CustomPainter` (силуэты рыб, иконки снастей, карта,
  древо навыков, «занавес-заброс»).
- **Админка** (`lib/admin/`, отдельный таргет) — **источник правды контента**:
  локации (создание точкой на карте с границами регионов, зарыбление, описания),
  **зоны заброса кистью по фону**, турниры, рыбы с профилями шансов клёва,
  весь каталог магазина, глобальные коэффициенты (прокачка/энергия/клёв/осадки),
  **загрузка своих картинок** (рыбы/предметы/фоны) и **экспорт/импорт** правок
  одним JSON. Правки хранятся оверрайдом поверх сида (общий стор с игрой);
  игра применяет их при запуске.
- **Тесты**: `test/` — поклёвка, экономика, уровни, эффективная редкость,
  ежедневка, энергия, турниры, **round-trip сериализации контента**, smoke
  (59 тестов).
- **Тема**: тёмная «мужская» (графит + янтарь), `lib/app/theme/`.

## Структура

```
lib/
  app/         providers.dart (DI), theme/
  domain/      entities/ value_objects/ services/ repositories/(интерфейсы)
  data/        seed/ repositories/(impl), content_overrides.dart (правки админки)
  features/    shell/ map/ fishing/ weather/ shop/ gear/ bestiary/ tournaments/
               achievements/ skills/ tasks/ tips/ daily/ profile/ menu/ splash/
  admin/       АДМИНКА: дашборд + редакторы (локации/зоны/турниры/рыбы/магазин/
               коэффициенты) — отдельный таргет main.dart
  shared/      rendering/, content_images.dart, sound_service.dart
  demo/        прежние прототипы Canvas+Flame (для справки)
docs/          GAME_DESIGN.md, ARCHITECTURE.md
assets/        locations/ (фоны), fish/ (фото рыб), art/ (меню/баннеры/рыбак),
               audio/ (синтезированные WAV), data/ (границы регионов РФ)
test/          domain/ features/ tools/ — юнит-тесты ядра, моделей, рендера
```

## Запуск

> ⚠️ Сеть/VPN: установка пакетов может виснуть на крупных архивах. Если
> `flutter pub get` застревает — **выключить VPN** и/или ставить через зеркало:
> ```powershell
> $env:PUB_HOSTED_URL = "https://pub.flutter-io.cn"
> flutter pub get
> ```

```powershell
cd C:\Work\nasha_rybalka
flutter pub get
flutter analyze              # чисто
flutter test                 # юнит-тесты ядра + моделей + smoke
flutter run -d windows       # запуск игры
flutter run -d windows -t lib/admin/main.dart   # запуск АДМИНКИ
# релизные сборки (админку копируем в свою папку, чтобы не перетереть игру):
flutter build windows --release -t lib/admin/main.dart
Copy-Item -Recurse -Force build\windows\x64\runner\Release build\admin_release
flutter build windows --release
```

Поток: сплэш → главное меню (берег) → Карта России → регион → водоём
(ИНФО/СОВЕТЫ) → «на воду». На сцене: тап по воде — заброс; на поклёвке — подсечка;
катушка снизу — подмотка/проводка/вываживание; разрез воды справа — глубина.

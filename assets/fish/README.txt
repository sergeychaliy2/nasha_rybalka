Сюда кладутся изображения рыб для бестиария и карточки улова.

Имя файла строго: fish_<id>.png  (id вида — см. список ниже)
Формат: PNG, 4:3 ландшафт, ~1280×960, рыба строго сбоку головой влево,
фон #11151A (цвет окна карточки) или прозрачный. Один общий «живописный» стиль.

Карточка подхватывает файл автоматически по пути assets/fish/fish_<id>.png.
Если файла нет — показывается рисованный силуэт (откат).
